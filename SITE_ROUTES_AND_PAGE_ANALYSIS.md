## 3. Redirection & Dynamic Routing Analysis

The original site utilizes three distinct redirection, state routing, and cross-linking mechanisms:

### A. URL Query Parameter Routing & History State Pushing (`country/index.html`)
- **Mechanism**: Uses `URLSearchParams` on page load to detect `?country={ISO}` (e.g. `?country=DEU`, `?country=USA`, `?country=NOR`).
- **DOM Action**: Automatically populates `#id_siteInput`, hides search list, dynamically fetches matching CSV data files from GitHub API / cache, loads the country's SVG images, and executes:
  ```javascript
  const newUrl = `${window.location.pathname}?${arg_name}=${site.iso}`;
  window.history.pushState({ path: newUrl }, '', newUrl);
  document.title = `${site.names[0]} – Country energy and emissions charts`;
  ```
- **Cross-Page Redirection Link (`seealso.json`)**: When an ISO matches one of the deeply tracked economies, the `#seeAlso` container injects a prominent cross-link:
  - `NOR` ➔ `https://robbieandrew.github.io/norway/`
  - `CHN` ➔ `https://robbieandrew.github.io/china/`
  - `IND` ➔ `https://robbieandrew.github.io/india/`
  - `NZL` ➔ `https://robbieandrew.github.io/newzealand/`
  - `USA` ➔ `https://robbieandrew.github.io/USA/`

### B. Vehicle Dataset Dedicated Page Redirections (`carsales/data.json`)
- In `carsales/data.json`, countries with comprehensive standalone portals redirect or link out:
  - **Norway** explicitly carries: `"dedicatedPage": "https://robbieandrew.github.io/EV/"`

### C. Download Interception & Citation Modal (`js/citation-modal.js`)
- Every `<a>` link targeting a `.csv` or `.xlsx` data download is intercepted by an event listener:
  - Prevents untracked downloads by rendering an in-page toast modal (#citationToast) encouraging citation of CICERO research with one-click clipboard copying.

### D. Slide Presentation Routing (`GCB2021`–`GCB2025`)
- Slide decks (`slides/index.html`) use **Reveal.js** hash routing:
  - Hash navigation: `#/0`, `#/1`, `#/2` for horizontal slide progressions.
  - Units toggle: Direct cross-links to `GtC/index.html` for figures in Gigatonnes of Carbon rather than $\text{GtCO}_2$.
